# Live Football Outcome Simulator

A sleek, weather-aware football outcome simulator built with Next.js. It uses live match signals such as score, possession, xG, shots, corners, and weather to estimate the probability of a home win, draw, or away win.

## Features

- Everton-focused example match logic
- Real-time sliders for score, possession, xG, corners, and weather
- Estimated win/draw/away probability output
- Monte Carlo simulation for a deeper outcome view
- Responsive dark-theme dashboard

## Getting started

1. Install dependencies:
   npm install
2. Start the app:
   npm run dev
3. Open http://localhost:3000

## Notes

This is a simulation engine designed for demonstration and analysis. It is not using live production sports APIs in this starter version.
